# RFID-учёт · Розница 2.2 Казахстан

Брифинг-страница для руководителя: внедрение учёта по RFID-меткам на стеке **1С Розница 2.2 (KZ) + Zebra MC3390R + Склад 15 RFID + Mobile SMARTS**.

## Открыть

- Локально: откройте `index.html` в браузере
- GitHub Pages: после публикации — `https://sania2007mav.github.io/rfid-retail-kz-briefing/`

## Содержание

1. Вердикт: проект реализуем через пилот  
2. Роли компонентов стека  
3. Что можно обещать бизнесу  
4. Влияние материала (металл, пластик, жидкости)  
5. Дорожная карта и риски
